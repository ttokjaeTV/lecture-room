# 강의실 시제품 (결제 제외)

Vimeo 강의 영상을 **로그인한 수강생에게만** 보여 주고, 회원별 **진도·시청 시간·시청 횟수**를 기록하고 제한하는 강의실입니다.
결제만 빠져 있고, 수강 권한은 관리자 화면에서 이메일로 부여합니다. (결제를 붙이면 결제 완료 시 같은 수강 권한이 자동으로 생기게 됩니다.)

---

## 1. 바로 체험하기 (데모 모드)

`index.html` 을 더블클릭해서 크롬으로 여세요. 서버 설정이 비어 있으면 **데모 모드**로 열립니다.

- 화면 위 검은 띠의 **[수강생 화면] / [관리자 화면]** 으로 오가며 볼 수 있어요.
- 데모 계정: `student@demo.com` / `admin@demo.com` (비밀번호 `demo1234`)
- 데모 영상은 Vimeo의 공개 샘플 영상입니다.
- 기록은 이 컴퓨터 브라우저에만 저장돼요. **[데모 초기화]** 로 처음 상태로 돌아갑니다.

### 입장 비밀번호
- 사이트를 열면 먼저 입장 비밀번호를 묻습니다. 한 번 맞히면 그 브라우저에서는 다시 묻지 않아요.
- 바꾸려면 `tools/password-hash.html` 을 열어 새 비밀번호를 넣고, 나온 값을 `js/config.js` 의 `SITE_PASSWORD_SHA256` 에 붙여넣습니다. 비워 두면 잠금이 꺼집니다.
- GitHub Pages는 서버 쪽 잠금을 지원하지 않아서, 이 잠금은 일반 방문자를 막는 용도예요. 코드를 직접 뜯어보는 사람까지 막지는 못합니다. 강의 영상 주소는 코드에 넣지 않고, 실제 운영 때는 로그인 + 수강 권한이 영상을 보호합니다.

## 2. 들어 있는 기능

| 구분 | 기능 |
|---|---|
| 수강생 | 회원가입·로그인·비밀번호 재설정 / 내 강의실(강의별 기간 D-day, 전체 진도) / 회차별 진도율·사용 횟수·이어보기 / 시청 화면(본 구간 막대, 남은 시청 시간, 커리큘럼) / 최근 시청 기록 |
| 시청 규칙 | **영상 길이만큼 재생 = 1회** (반복·되감기 포함, 건너뛴 부분 제외) / 회차당 최대 횟수 넘으면 정지 / 수강 기간 만료 시 정지 / **같은 계정은 한 창에서만 재생** (계정 공유 방지) |
| 관리자 | 수강생 목록·검색·필터 / 이메일로 수강 권한 부여(여러 명 한 번에, **가입 전 이메일도 가능** → 그 이메일로 가입하는 순간 자동 연결) / 기간 연장·무제한·해지 / 회차별 **+1회 추가, 횟수 초기화** / 회원별 시청 기록(날짜·회차·시청 시간·기기) |
| 강의 관리 | 강의 만들기(회차당 최대 횟수, 기본 수강 기간, 공개 여부) / 회차 추가(Vimeo 링크·임베드 코드 붙여넣기, **영상 길이 자동 불러오기**) |
| 통계 | 강의별 수강생·시청 시작률·평균 진도·완강자 / 회차별 시청자·완료·평균 사용 횟수 / **20구간 이탈 그래프와 가장 많이 빠지는 지점** |

### 시청 기록이 정확한 이유
- 10초마다 "실제로 재생된 구간"을 서버로 보냅니다. 위치가 아니라 구간이라, 끝으로 건너뛰기만 해서 진도 100%를 만들 수 없어요.
- 서버는 지난 기록 이후 흐른 실제 시간의 **2배(최대 배속) + 3초** 넘는 재생량은 인정하지 않습니다. 기록을 부풀리는 조작을 막습니다.
- 기록 저장이 3번 연속 실패하면 재생을 멈춥니다(기록 없이 보는 것 방지).
- 창을 닫는 순간에도 마지막 기록이 전송됩니다.

### 한계 (솔직하게)
- 화면 녹화는 막을 수 없습니다. 개발 지식이 있는 사람이 기록 전송 자체를 막으면 우회 여지도 있습니다. 일반 수강생 대상으로는 충분한 수준이고, 완벽한 차단(DRM)은 Vimeo Enterprise 급이 필요합니다.

## 3. 실제 운영 연결 (Supabase)

Supabase = 회원·DB를 맡아 주는 서비스. 별도 서버 없이 지금처럼 정적 홈페이지(GitHub Pages 등)에 올려도 동작합니다.
※ 메뉴 이름은 Supabase 화면 개편에 따라 조금 다를 수 있어요.

1. **프로젝트 만들기** — supabase.com 가입 → New project (지역은 Seoul 권장)
2. **DB 설정** — 왼쪽 메뉴 SQL Editor → `supabase/schema.sql` 전체를 붙여넣고 **Run**
3. **키 넣기** — Project Settings → API 에서 `Project URL` 과 `anon`(또는 `publishable`) 키를 복사해 `js/config.js` 에 입력
   - 이 키는 공개용이라 홈페이지 코드에 넣어도 됩니다. 데이터 보호는 schema.sql 의 접근 정책(RLS)이 담당해요.
   - **`service_role`(secret) 키는 절대 넣지 마세요.**
4. **주소 등록** — Authentication → URL Configuration
   - Site URL: 강의실 주소 (예: `https://내도메인/lecture/`)
   - Redirect URLs: 같은 주소 추가 (인증 메일·비밀번호 재설정 링크가 돌아올 곳)
5. **메일 발송 설정 (중요)** — Supabase 기본 메일은 테스트용이라 프로젝트 팀원 이메일로만, 시간당 몇 통만 보내집니다. 실제 수강생에게 인증·비밀번호 재설정 메일이 가려면 Authentication → SMTP Settings 에서 외부 메일 서비스를 연결해야 해요.
   - **이메일 인증(Confirm email)은 켜 두세요.** 꺼 두면 남이 구매자 이메일로 먼저 가입해서 미리 부여한 수강 권한을 가로챌 수 있습니다.
6. **관리자 지정** — 강의실 페이지에서 본인 이메일로 회원가입 → SQL Editor 에서 실행
   ```sql
   update public.profiles set is_admin = true where email = '내이메일@example.com';
   ```
7. 다시 로그인하면 상단에 **관리자** 메뉴가 생깁니다. 강의·회차 등록 → 수강생 권한 부여 순서로 진행하세요.

### 비용 참고
- Supabase 무료 플랜은 1주일 동안 접속이 없으면 프로젝트가 일시정지됩니다. 실제 판매를 시작하면 Pro(월 $25) 를 권장해요. 요금은 바뀔 수 있으니 supabase.com/pricing 에서 확인하세요.

## 4. Vimeo 설정

- 영상 공개 범위: **비공개 링크 + "Vimeo에서 숨기기"**, 임베드는 **특정 도메인만 허용** 에 강의실 도메인을 추가
- 도메인 제한 임베드는 Vimeo **Core 이상** 요금제에서 제공됩니다.
- 도메인 제한을 걸면 **내 컴퓨터에서 파일로 연 페이지에서는 재생되지 않습니다.** 실제 도메인에 올린 뒤 확인하세요.
- 회차 등록 때 Vimeo 링크를 붙여넣고 **[길이 불러오기]** 를 누르면 길이가 자동으로 채워집니다. 길이는 시청 횟수 계산의 기준이라 정확해야 해요.

## 5. 홈페이지에 붙일 때

- 이 폴더 전체를 홈페이지의 하위 폴더(예: `/lecture/`)로 올리면 됩니다.
- `js/config.js` 에서 `SITE_NAME`, `PURCHASE_URL`(상품 페이지), `HOME_URL`, `CONTACT_TEXT` 를 바꾸세요.
- 디자인은 계산기 톤(크림 베이지 + 오렌지)으로 맞춰 두었고, 색은 `css/style.css` 맨 위 변수에서 바꿀 수 있어요.

## 6. 결제를 붙일 때 (다음 단계)

결제 완료 → PG사(토스페이먼츠 등) 서버 알림 → Supabase Edge Function 이 결제를 검증하고 `enrollments` 에 `source='payment'` 로 수강 권한을 넣는 구조입니다. 화면·시청 기록 쪽은 고칠 필요가 없습니다.

## 파일 구조

```
index.html                 강의실 페이지 (하나의 페이지에서 화면 전환)
js/config.js               설정 (여기만 고치면 됨)
js/core.js                 시청 구간·횟수 계산 규칙
js/tracker.js              Vimeo 재생 이벤트 → 구간 기록·전송
js/app.js                  화면 (로그인·내 강의실·시청·관리자)
js/backend-supabase.js     실제 서버 연결
js/backend-demo.js         데모 모드 (브라우저 저장)
css/style.css              디자인
supabase/schema.sql        DB·접근 권한·함수 (Supabase SQL Editor 에서 실행)
tests/                     자동 테스트 (개발용)
```
